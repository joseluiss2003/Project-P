# Project P

A personal Hyprland desktop environment built around a strong visual identity.

Project P is not intended to be another generic Linux rice or an Omarchy replacement. It is a personal desktop experience designed around José Luis's own preferences, using Hyprland and Quickshell as its foundation.

## Vision

Project P combines:

- Linux freedom and modularity
- Hyprland + Wayland
- Quickshell
- Modern Android interaction patterns
- Nothing OS 4 as a major visual reference
- Industrial design
- Floating capsule-based UI
- Contextual information
- Carefully designed motion
- Coherent, hand-designed themes

The goal is simple:

> Build the Linux desktop I personally want to use every day.
